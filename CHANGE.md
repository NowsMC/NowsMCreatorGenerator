# Change

## 2026.2-0.2.0

- Added a dedicated **Nows mod** workspace entry through the bundled Java integration; users install only one plugin ZIP.
- Kept Nows isolated from the normal Fabric workspace selector even though MCreator 2026.2 requires an internal compatible generator flavor.
- Added the Nows logo to the dedicated workspace entry.
- Marked the generator as experimental so MCreator 2026.2 can load its status correctly.

## 2026.2-0.1.0

- Added the first Nows MCreator generator for Minecraft 26.2 and MCreator 2026.2.
- Generated Nows Gradle workspaces with stable item, block, creative tab, command, data, event, keybind, config, NBT, client UI and recipe viewer templates.
- Updated generated projects to target Nows Loader 0.9.1.
- Added stable recipe catalyst generation using Nows-owned `McItemStack` values.
